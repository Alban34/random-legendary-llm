## What is this?

Legendary: Marvel Randomizer is a free, browser-based companion app for players of *Legendary: A Marvel Deck-Building Game*. Open the URL. Get a legal, fresh, collection-aware game setup in seconds. No install. No account. No tracking. Ever.

## What's in v2.1.3

---

### Replay from History

Users can replay any previous game from the History tab with the exact same cards, re-entering the standard acceptance flow without any re-randomisation.

---

### Data fix: Hank Pym, Yellowjacket mastermind corrected

The forced villain group lead field was incorrectly set to "Black Order Guards"; corrected so the mastermind can lead any villain group.

---

### SonarCloud code quality cleanup (Epic 101)

A type-system-only pass resolved all remaining SonarCloud code smell issues: redundant type casts were removed and `&&`-based null-guard chains were replaced with optional chaining across 8 source files (`bgg-import-utils.ts`, `game-data-indexes.ts`, `history-vm.svelte.ts`, `localization-utils.ts`, `result-utils.ts`, `setup-generator.ts`, `setup-rules.ts`, `setup-validator.ts`). No user-facing behaviour was changed.
